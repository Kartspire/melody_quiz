# Формат `.melody`

`.melody` — ZIP-контейнер приложения. Он используется для переноса игры или медиатеки и отличается от полной резервной копии приложения.

## Основные принципы

- manifest содержит тип и версию package;
- JSON-файлы проходят schema/domain validation до применения;
- аудио проверяется по фактической сигнатуре контейнера;
- SHA-256 используется для content-addressed identity;
- CRC32 и ограничения ZIP защищают от повреждений и неконтролируемого распаковывания;
- импорт сначала строит preview/merge plan и только затем изменяет persisted state.

## Идентичность при merge

MediaTrack считается семантически эквивалентным существующему, когда совпадают нормализованное имя и SHA-256 физического аудио.

Song дедуплицируется только при совпадении artist/title и уже сопоставленных `minusTrackId` / `plusTrackId`. Одно название песни само по себе недостаточно для объединения.

Несколько логических MediaTrack могут ссылаться на один AudioAsset; физический Blob при этом хранится один раз.

## Full backup

Full backup — отдельный формат disaster recovery. Он дополнительно содержит `GameSession` и `activeGameId` и предназначен для восстановления состояния приложения целиком.

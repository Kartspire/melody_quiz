# Melody Quiz — legacy session test fix

Исправлены два legacy-fixture в `src/model/session.test.ts`.

Причина: `createSession()` теперь создаёт современное поле `stageId`, но тесты моделировали старые сохранения через spread современного объекта. В реальных legacy-сессиях `stageId` отсутствовал.

Изменение: в двух legacy-сценариях явно задано `stageId: undefined`.

Production-код не изменён: при наличии современного `stageId` он по-прежнему имеет приоритет над индексом, что необходимо для корректной работы после перестановки этапов.

# Угадай мелодию — локальная версия v1.3.4

Приложение ведущего для игры «Угадай мелодию» на React + Effector + TypeScript + Vite.


## Изменения v1.3.4

- полностью убраны CSS-градиенты: фон приложения, игровое поле, карточки вопросов, экран проигрывания и карточка активной сессии используют спокойные однотонные оттенки;
- hover-состояния больше не сдвигают кнопки и карточки вверх: удалены `translateY`, вместо движения используется очень мягкая подсветка фона/границы;
- разрешено удалить последнюю игру и оставить библиотеку игр пустой; состояние `0 игр` сохраняется в IndexedDB и не восстанавливает стартовую игру после перезапуска;
- для пустой библиотеки игр добавлен отдельный экран с действиями «Создать игру» и «Импортировать игру»;
- любую песню теперь можно удалить даже если она используется в играх: перед удалением показывается предупреждение, а песня автоматически снимается со всех связанных вопросов, чтобы не оставлять битые `songId`;
- после удаления последней песни медиатека корректно остаётся пустой, связанные неиспользуемые Blob-аудио очищаются как раньше.


## Изменения v1.3.3

- экран проверки перед импортом игры переработан: вместо технических SHA-256/CRC показывается понятный статус готовности архива;
- отдельно показывается, сколько песен и аудиофайлов находится в архиве, сколько уже есть в медиатеке и сколько реально будет добавлено;
- если всё содержимое уже есть, интерфейс прямо сообщает, что будут переиспользованы существующие данные и дубликаты не создадутся;
- импорт медиатеки приведён к тому же понятному формату; техническая проверка контрольных сумм сохранена внутри механизма, но больше не перегружает интерфейс;
- после отметки **«Неверно»** команда сразу блокируется до конца текущей песни и больше не может получить баллы за неё;
- ошибившаяся команда по-прежнему пропускает ровно одну следующую песню;
- ведущий может отменить ошибочную отметку кнопкой **«Отменить ошибку»**, после чего команда снова может отвечать в текущей песне и штраф на следующую снимается;
- состояние «ошиблась в текущей песне» отделено от состояния «пропускает текущую песню», чтобы штрафы не смешивались;
- возврат из незавершённой песни отменяет новые ошибочные ответы этой попытки, но не расходует штраф, который команда получила за предыдущую завершённую песню.

## Изменения v1.3.1

- новая игра создаётся с **1 раундом и 1 категорией**; каждый новый раунд тоже начинается с одной категории;
- все меню `⋯` переведены на единый управляемый popover и закрываются по действию, клику вне меню, повторному клику, `Escape`, уходу фокуса и потере фокуса окна;
- при открытии меню фокус переводится на первое доступное действие, а `Escape` возвращает его на кнопку `⋯`;
- импортные диалоги и выбор песни закрываются по `Escape` и клику по фону;
- нельзя удалить последний раунд, последнюю категорию или последний вопрос и оставить неиграбельную структуру;
- лимиты редактора синхронизированы с форматом экспорта: до 10 раундов, 100 категорий в раунде, 100 вопросов в категории и 32 команд;
- перед стартом/продолжением выполняется проверка готовности: названия игры/команд/раундов/категорий, уникальность названий и цветов команд, положительная и уникальная стоимость вопросов в категории, наличие песни, минуса и плюса;
- пустые/повреждённые аудиофайлы блокируют запуск до исправления;
- при редактировании игры с сохранённой партией показывается предупреждение и доступен явный сброс прогресса;
- случайный сброс уже начатой партии требует подтверждения;
- ручной ввод стоимости вопроса и счёта команды допускает очистку поля, выделяет текущее значение при фокусе и нормально заменяется прямым вводом;
- медиатека показывает отдельное состояние «Ничего не найдено» для пустого результата поиска;
- заменённые/удалённые аудиофайлы очищаются из runtime-state, если больше нигде не используются;
- IndexedDB больше не переписывает все большие Blob-аудио при каждом мелком изменении редактора: существующие аудиофайлы сохраняются инкрементально;
- ошибки открытия/сохранения IndexedDB больше не проходят незаметно: приложение показывает глобальное предупреждение о риске потери несохранённых данных;
- экспорт дополнительно проверяет целостность ссылок на песни/аудио, импорт валидирует timestamps, цвета команд, структуру game.json/manifest и метаданные аудио;
- исправлен счётчик назначенных песен на карточке игры при повторном использовании одной песни;
- sidebar не теряет информацию о сохранённой партии, если ведущий открыл редактор другой игры.

## Экспорт и импорт (добавлено в v1.2.0)

### Экспорт отдельной игры

На карточке каждой игры появилась кнопка **«Экспортировать игру»**.

Создаётся файл с расширением `.melody`, который содержит:

- настройки выбранной игры;
- раунды, категории, вопросы и команды;
- только те песни из общей медиатеки, которые используются этой игрой;
- все используемые минусы и плюсы.

Текущая игровая сессия (баллы, сыгранные карточки, текущий раунд и штрафы) специально не экспортируется. Импортированная игра всегда готова к новой партии.

### Импорт игры

На экране **«Мои игры»** появилась кнопка **«Импортировать игру»**.

Перед изменением данных приложение:

1. открывает архив;
2. проверяет версию формата;
3. проверяет обязательные файлы;
4. сверяет размеры;
5. проверяет SHA-256 каждого файла;
6. проверяет CRC ZIP-записей;
7. анализирует песни и аудио относительно текущей медиатеки;
8. показывает сводку импорта.

Если игра с тем же постоянным `gameId` уже существует, можно выбрать:

- **Заменить существующую** — обновить конфигурацию этой игры и начать новую сессию;
- **Импортировать как копию** — оставить существующую игру и создать новую с новым `gameId`.

Совпадение по одному названию игры конфликтом не считается.

### Дедупликация песен и аудио

При импорте песни сравниваются по:

- нормализованному исполнителю;
- нормализованному названию;
- SHA-256 минуса;
- SHA-256 плюса.

Аудиофайлы дедуплицируются глобально по SHA-256 содержимого. Если тот же MP3 уже есть в медиатеке, второй Blob в IndexedDB не создаётся.

Одинаковое название с другим минусом или плюсом считается отдельной песней — такие версии не объединяются автоматически.

### Экспорт и импорт всей медиатеки

На экране **«Медиатека»** появились кнопки:

- **«Экспортировать медиатеку»**;
- **«Импортировать медиатеку»**.

Экспорт создаёт `.melody-library` со всеми песнями, минусами и плюсами. Импорт работает как merge: новые песни добавляются, существующие переиспользуются, одинаковые аудиофайлы не копируются повторно.

### Формат архива

`.melody` и `.melody-library` являются ZIP-совместимыми контейнерами без повторного сжатия аудио. MP3/WAV/OGG уже являются большими бинарными файлами, поэтому приложение не пытается держать дополнительно сжатую копию каждого трека в памяти.

Пример структуры `.melody`:

```text
manifest.json
game.json
songs.json
audio/
  <sha256>.mp3
  <sha256>.mp3
```

`manifest.json` содержит `formatVersion`, версию приложения, дату экспорта и SHA-256 каждого файла. Это позволяет в дальнейшем мигрировать старые архивы и обнаруживать повреждение до записи данных.

### Транзакционный импорт

После проверки приложение сначала формирует итоговое состояние целиком, затем сохраняет игры, песни, аудио, сессии и служебные данные одной IndexedDB-транзакцией. Только после успешной записи новое состояние применяется в Effector.

Повреждённый или неподдерживаемый архив не должен оставлять базу в частично импортированном состоянии.

## Хранение рабочего состояния

Рабочие данные по-прежнему находятся в IndexedDB:

- `games` — конфигурации игр;
- `songs` — общая медиатека;
- `audio` — Blob-файлы минусов и плюсов;
- `sessions` — игровые сессии;
- `meta` — служебные данные.

Экспорт теперь даёт переносимую резервную копию конкретной игры или всей медиатеки, поэтому IndexedDB больше не является единственной копией подготовленного контента.

## Возможности из v1.1

- несколько независимых игр;
- дублирование игр;
- общая медиатека;
- одна песня может использоваться в нескольких играх;
- отдельная игровая сессия для каждой игры;
- продолжение незавершённой игры;
- неправильный ответ блокирует команду до конца текущей песни и исключает её из следующей песни на один розыгрыш;

- ручная корректировка баллов;
- автоматический переход между раундами.

## Проверка

```bash
npm run build
npm test
```

Тесты экспорта/импорта проверяют:

- экспорт и восстановление игры с аудио;
- повторный импорт той же игры без дублирования песен и Blob-файлов;
- экспорт/импорт медиатеки с дедупликацией.

### Текущее ограничение размера

Экспорт использует ZIP32 без сжатия, поэтому один `.melody` / `.melody-library` должен быть меньше 4 ГБ. Для стартовой локальной версии этого обычно достаточно; при росте медиатеки выше этого размера следующий шаг — ZIP64/потоковая запись через desktop-оболочку или File System Access API.

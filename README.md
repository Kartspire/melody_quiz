# Добавление результатов обработки в медиатеку

Распакуйте архив в корень проекта с заменой файлов.

Добавлено:
- «Добавить в медиатеку» для обрезанного WAV;
- «Добавить в медиатеку» для готового минуса;
- сохранение через существующие AudioAsset + MediaTrack и IndexedDB;
- content-addressed дедупликация физического аудио по SHA-256;
- защита от повторного добавления одного результата в рамках страницы;
- локальное отображение ошибки добавления;
- regression-тест кнопки добавления и тест нормализации имени медиатрека.

# Угадай мелодию — React + Effector

Готовый локальный MVP приложения для проведения игры «Угадай мелодию».

## Что реализовано

- React + TypeScript + Vite.
- Effector для конфигурации игры и состояния игровой сессии.
- Админ-панель:
  - количество раундов;
  - название каждого раунда;
  - произвольное количество категорий;
  - произвольное количество песен/вопросов;
  - стоимость вопроса;
  - исполнитель и название песни;
  - загрузка отдельного «минуса» и «плюса»;
  - произвольное количество команд, название и цвет.
- Игровой экран:
  - категории и карточки со стоимостью;
  - автоматический запуск минуса при выборе карточки;
  - пауза/продолжение и перемотка;
  - начисление стоимости вопроса выбранной команде;
  - после правильного ответа запускается «плюс»;
  - разыгранный вопрос исчезает с игрового поля;
  - после последнего вопроса переход к следующему раунду;
  - финальный рейтинг после последнего раунда.
- Счёт команд постоянно виден сверху.
- Ручная коррекция счёта: клик по числу баллов команды.
- Автосохранение конфигурации, аудиофайлов и текущего прогресса в IndexedDB.

## Запуск

Требуется Node.js 20.19+ или 22.12+ (требование Vite 7).

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Как пользоваться

1. Откройте «Настройки».
2. Задайте команды и цвета.
3. Настройте раунды, категории и песни.
4. Для каждой песни загрузите два аудиофайла:
   - **Минус** — фрагмент для угадывания.
   - **Плюс** — оригинал/фрагмент с вокалом, который включается после правильного ответа.
5. Нажмите «Начать новую игру».
6. Ведущий выбирает карточку — минус стартует автоматически.
7. Кнопкой воспроизведения ведущий ставит трек на паузу или продолжает его.
8. При правильном ответе ведущий нажимает на нужную команду. Баллы начисляются сразу, после чего включается плюс.
9. Кнопка «Вернуться к карточкам» завершает вопрос. Если это был последний вопрос раунда, откроется следующий раунд.

## Хранение данных

Приложение работает без backend. Конфигурация и аудиофайлы сохраняются в IndexedDB текущего браузера.

Это удобно для локального проведения игры на одном ноутбуке. Если позже потребуется несколько ведущих, общий сервер, вход по аккаунту или синхронизация между устройствами, слой хранения можно заменить на API/объектное хранилище без изменения основной модели игры.

## Структура

- `src/model/game.ts` — Effector-модель, события, сторы, игровая логика.
- `src/model/types.ts` — основные типы.
- `src/lib/storage.ts` — IndexedDB.
- `src/components/AdminPanel.tsx` — админка.
- `src/components/GameBoard.tsx` — раунды и карточки.
- `src/components/AudioQuestion.tsx` — экран вопроса и аудиоплеер.
- `src/components/Scoreboard.tsx` — счёт и ручная корректировка.

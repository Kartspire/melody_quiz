# Угадай мелодию

Локальное браузерное приложение для подготовки и проведения игр «Угадай мелодию». Игры, медиатека, аудиофайлы и прогресс партий хранятся на устройстве ведущего в IndexedDB; сервер для обычной работы не требуется.

## Возможности

- несколько независимых игр с раундами, категориями, командами и межраундами;
- общая медиатека песен и переиспользуемых аудиотреков;
- content-addressed хранение физических аудиофайлов по SHA-256;
- импорт/экспорт игр и медиатеки в `.melody`;
- полная резервная копия приложения вместе с прогрессом партий;
- полноценный browser-only аудиоредактор с многодорожечным таймлайном, trim/split, multi-select, copy/paste через горячие клавиши, snapping, маркерами, waveform, индивидуальной громкостью, fade, скоростью, mute, undo/redo через горячие клавиши и WAV-рендером;
- browser-only нарезка аудио и создание instrumental-версии через HTDemucs;
- автоматическое сохранение с защитой от конфликтов между вкладками;
- восстановление игровой сессии после перезагрузки страницы;
- безопасное восстановление из полной резервной копии при ошибке чтения локального хранилища.

## Запуск

Требуется Node.js 18+.

```bash
npm ci
npm run dev
```

Приложение открывается на `http://127.0.0.1:5173`.

## Основные команды

```bash
npm run dev           # локальная разработка
npm run typecheck     # проверка TypeScript
npm test              # unit + regression tests
npm run build         # TypeScript + production build
npm run check         # основной локальный quality gate: tests + build
npm run test:browser  # сервер для ручных browser/IndexedDB regression checks
```

`npm run test:browser` запускает Vite в отдельном режиме на `http://127.0.0.1:5185`. После запуска откройте `http://127.0.0.1:5185/tests/browser/storage.html` и нажмите «Запустить проверки».

Браузерные проверки используют отдельную базу `melody-quiz-test-db` и не изменяют рабочую базу приложения. Они проверяют реальные транзакции IndexedDB, восстановление после повреждения данных и конфликт записи между двумя вкладками. Эти проверки пока запускаются вручную и не входят в `npm run check`.

На том же сервере страница `http://127.0.0.1:5185/tests/browser/audio-editor.html` проверяет амплитуду готового WAV в настоящем Web Audio: пересекающиеся и раздельные fade, диапазоны, общий gain, mute, наложения и короткий экспорт из длинного проекта. Также проверяются повтор диапазона, стереометры и живое изменение master/gain/mute/fade. Нажмите «Запустить проверки». Все данные синтетические и находятся в памяти; IndexedDB не используется.

## Архитектура данных

Ключевая цепочка медиатеки:

```text
Song
  ↓ minusTrackId / plusTrackId
MediaTrack
  ↓ audioId
AudioAsset
  ↓ sha256 / Blob
IndexedDB

AudioProject
  ↓ sourceTrackId
MediaTrack
```

`Song` хранит музыкальную сущность, `MediaTrack` — логическое использование конкретной записи, `AudioAsset` — физический файл. Несколько `MediaTrack` могут ссылаться на один физический `AudioAsset`. `AudioProject` хранит только недеструктивный монтаж: дорожки и фрагменты со ссылками на `MediaTrack`, поэтому исходные Blob-файлы не копируются и не изменяются.

В аудиоредакторе новый исходник добавляется в позицию курсора и не сдвигает существующий материал. Удаление также оставляет свободное место на таймлайне. Фрагменты магнитятся к курсору, маркерам и границам других клипов. `Ctrl/Cmd` или `Shift` позволяют выбирать несколько фрагментов, а `Ctrl/Cmd+C` / `Ctrl/Cmd+V` копируют и вставляют их с сохранением взаимного расположения. Копирование и вставка выполняются горячими клавишами; отмена и возврат доступны также кнопками над таймлайном. Горячие клавиши определяются по физическим клавишам (`KeyboardEvent.code`) и не зависят от текущей раскладки клавиатуры.

Редактор использует единый полный интерфейс без переключения режимов и встроенного обучающего гайда. Числовые параметры выбранного фрагмента поддерживают свободный ввод дробных значений через точку или запятую: поле можно временно очистить, а значение фиксируется при Enter или потере фокуса. На дорожках доступен Mute; Solo больше не участвует в воспроизведении и рендере. Fade In и Fade Out задаются вручную ручками на фрагменте или числовым вводом; наложение клипов не изменяет эти настройки. Масштаб меняется только через `Ctrl/Cmd + колесо` при наведении на таймлайн и сохраняет позицию под указателем. Базовые горячие клавиши: `Space` — play/pause, `S` — split активного фрагмента, `Delete` — удалить выделение, `Ctrl/Cmd+C` / `Ctrl/Cmd+V` — copy/paste, `Ctrl/Cmd+Z` и `Ctrl/Cmd+Shift+Z`/`Ctrl/Cmd+Y` — undo/redo.

Игровая логика отделена от Effector orchestration: редактирование конфигурации и переходы сессии находятся в pure domain-функциях, а Effector связывает команды с UI и persistence.


## Возможности аудиоредактора

- История до 100 действий и состояние каждого проекта (курсор, выделение, масштаб, диапазон) сохраняются при переходах между разделами до перезагрузки страницы. Импорт полной копии сбрасывает сессию и историю. Копия монтажа использует те же исходники с новыми ID проекта, дорожек и фрагментов.
- Диапазон выделяется протягиванием по линейке и меняется ручками или числами. Он независим от выделения клипов. Alt временно отключает привязку; перенос группы между дорожками сохраняет расстояния между её фрагментами. Поле курсора поддерживает точность 1 мс.
- Диапазон можно прослушать, повторять (от 50 мс) и экспортировать. Повтор планируется по времени AudioContext с очередью вперёд; при сильном ограничении фоновой вкладки возможен перерыв, после которого устаревшие циклы пропускаются. Перемещение и обрезка останавливают звук с сохранением позиции; gain, mute и fade меняются во время звучания.
- Общая громкость входит в итоговый WAV. Стереометры показывают текущие пики, удерживают максимумы до сброса и отмечают перегрузку. Пиковая нормализация устанавливает потолок −1 dBFS. LUFS-нормализация использует K-взвешивание и шлюзы по [ITU-R BS.1770-5](https://www.itu.int/rec/R-REC-BS.1770-5-202311-I/en); при недостаточном запасе по пику целевая громкость ограничивается. Это sample peak, без true-peak лимитера. Анализ итогового микса выполняется отдельно, применение громкости отменяется через Undo.
- Исходники можно искать, прослушивать и импортировать несколькими файлами кнопкой или перетаскиванием на дорожку. Файлы добавляются последовательно с прогрессом и отдельными ошибками. При смене проекта, удалении целевой дорожки или восстановлении данных отложенная вставка отменяется; уже добавленные файлы остаются в медиатеке.
- До 100 именованных диапазонов хранятся в проекте. Для пакета выберите диапазоны и назначение: отдельные треки в медиатеке или ZIP. Имена повторного экспорта в медиатеку получают числовые суффиксы. Каждый WAV ограничен 10 минутами, ZIP — 256 МБ исходного PCM; пакет рендерится последовательно из снимка проекта на момент запуска. Отмена не запускает следующие файлы и не сохраняет результат незавершённого рендера; уже сохранённые треки остаются.

Новые поля `masterGainDb` и `ranges` необязательны в формате v5: старые проекты открываются с усилением 0 dB и без диапазонов. IndexedDB и полная резервная копия сохраняют эти поля; историю Undo резервная копия не включает.

## Надёжность хранения

Импорт и полное восстановление выполняются как исключительные операции: на время замены состояния пользовательские записи блокируются, а запущенные до импорта асинхронные операции не могут дописать устаревшие данные после завершения замены.

Если первичная загрузка IndexedDB завершается ошибкой, приложение открывает отдельный экран восстановления. Полная резервная копия сначала проверяется, затем все разделы состояния заменяются одной транзакцией.

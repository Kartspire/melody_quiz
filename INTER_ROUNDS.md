# Межраунды

## Модель

Игра хранит обычные раунды и межраунды отдельно, а фактический порядок задаёт `GameConfig.stages`.

```text
GameConfig
  rounds[]
  interRounds[]
  stages[] -> round | interRound
```

Межраунды не создают `Song`. Любое используемое ими аудио выбирается напрямую из общей медиатеки через `MediaTrack`, поэтому исполнитель/название, минус и плюс для такого аудио не обязательны.

## Библиотека шаблонов

Чистые описания шаблонов находятся в `src/interRounds/templates.ts`. Каждый экземпляр хранит `templateId` и `templateVersion`.

Доступны:

- `continueLyrics` — «Продолжи песню»;
- `commonTheme4` — «4 трека — общая тема».

Общий lifecycle межраунда:

```text
INTRO -> PLAY -> ANSWER -> NEXT STAGE
```

Перед каждым межраундом обязательно показывается экран правил. Счёт за первые шаблоны ведущий меняет вручную через существующее табло команд.

## Продолжи песню

Каждое задание содержит:

- `trackId`;
- `cutAtMs`;
- `requiredWordsCount`;
- `answerText`.

Во время игры трек останавливается в заданной точке. После сдачи бланков показывается текст ответа и воспроизводится тот же `MediaTrack` целиком с самого начала.

## 4 трека — общая тема

Межраунд содержит массив `stages[]`. Каждый внутренний этап хранит ровно четыре элемента с:

- `trackId`;
- `answerTitle`;
- `answerArtist`.

У каждого этапа своя `commonTheme`. После четырёх треков показываются ответы текущего этапа, затем ведущий переходит к следующему. `GameSession.interRound.taskIndex` хранит номер внутреннего этапа, а `trackIndex` — прогресс прослушивания 0..4.

Шаблон `commonTheme4` имеет `templateVersion: 2`. Старый v1-объект (`tracks + commonTheme`) автоматически превращается в один элемент `stages[]`; старый session `taskIndex`, который обозначал номер трека, мигрирует в `trackIndex`.

## Экспорт и совместимость

`.melody` formatVersion 4 включает `MediaTrack`/Blob, которые используются только межраундами. Архивы v1–v3 и игры без `stages` автоматически мигрируют в текущую модель.

## Добавление следующего шаблона

Для нового типа нужно:

1. добавить вариант в `InterRoundTemplateId` и union `InterRound`;
2. зарегистрировать metadata/default factory в `src/interRounds/templates.ts`;
3. добавить его editor и player;
4. добавить template-specific validation;
5. расширить helpers работы со ссылками на `MediaTrack` и миграцию версии шаблона, если структура меняется;
6. добавить unit/smoke tests экспорта и игрового lifecycle.
